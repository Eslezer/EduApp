# Puzzle Trail

Puzzle Trail is a visual-maths adventure for Android. Players will solve picture puzzles, collect stars, and progress through a themed learning trail.

This project is built with Kotlin and Jetpack Compose.

The app contains 18 visual puzzles across three chapters, with locked level progression, hints, answer reveals, and a score that drops by 10 points after each wrong attempt. Room stores attempts, completed levels, and scores locally so progress remains available after the app is closed.
